How to Use It Day-to-Day
At school: Just run npm run dev or npm run dev:electron (local-only, invisible on school Wi-Fi).
At home (with your phone): Run npm run dev:lan (or npm run start:lan), open Settings on your laptop, click Copy Phone Link, and open it on your phone once—it stays signed in for 30 days.
